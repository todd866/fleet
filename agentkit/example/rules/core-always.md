# Operating rules (example)

These are loaded into every agent session on every provider. Keep them short: the byte budget
is checked by `agentkit doctor`. Put detail in on-demand files and skills.

- Never hard-delete outside temp directories. Move things to the Trash.
- Check for a metered link before any large transfer.
- Heavy builds and test suites run through the slot limiter, or on a worker Mac.
- Pushing, posting or publishing on the owner's behalf needs a yes for that action.
- A guard that refuses is satisfied, never dodged: do the task the documented way.
- At session start and before finishing, read unread agent mail.
