# Agent operating inventory

Generated by `agentkit inventory`. Edit the catalogue in `agentkit/src/inventory.rs`, then regenerate this file. Site data (hosts, rules, addresses) stays in `~/.config/agentkit`, not here.

Coupling is what is true of the hand-maintained layer today. The neutral home is where agentkit keeps the one copy.

## Gaps

- **Cursor** — No status-line hook, so capacity and mail are not on screen between prompts. Mitigation: `beforeSubmitPrompt` and `sessionStart` run `agent-context`, and the always-applied rule tells the session to read it.
- **Cursor** — User hooks in `~/.cursor/hooks.json` are the enforcement point. A surface that does not load that file will not run the guards. Mitigation: The same prohibitions are in the always-applied rule. `agentkit doctor --provider cursor` checks the file is wired and that the guard self-test still denies `rm -rf` outside temp and `trash ~/Documents`. It cannot see a running IDE.
- **Cursor** — No `ScheduleWakeup` and no Claude-style background task. Mitigation: Overnight work is a shell loop or a launchd job that calls `ai-pick`. Do not expect a Cursor session to wake itself.
- **Codex** — Hooks exist (`~/.codex/hooks.json`, same decision JSON as Claude) but there is no status line. Mitigation: SessionStart and UserPromptSubmit run `agent-context`. A shell wrapper is not required while hooks.json is loaded.
- **Codex** — No `ScheduleWakeup`. Mitigation: Same as Cursor: launchd or an explicit loop.
- **Claude, Codex, Cursor** — An agent that can edit its own hook file can disable a guard. That was already true of `~/.claude/settings.json`. Mitigation: Doctor flags a missing hook command. Do not grant the session write access to the hook file on an unattended day.
- **all** — MCP tokens and connector secrets are not in the canonical site. Mitigation: Leave them in each provider's private config. Sync does not read or write them.
- **all** — Headless-worker hard-delete exemption is config, not a built-in hostname. Mitigation: Put worker aliases in `guards.air_aliases` before `sync --apply`, or deletes on that worker stay denied.
- **all** — Email-in-command denial needs a private substring file. Mitigation: Set `guards.email_substrings_file`. The addresses never go in the repo. Until the file exists, the legacy Claude hook still carries that rule if it is left installed.
- **all** — Generated hooks call `agentkit` and `agent-context` by absolute path (`~/.local/bin`, or `hook_bin` in the site). Mitigation: Install both there before `sync --apply`. Doctor fails when the hook program is missing. The guard refuses agents writing either file, but any same-user process can; a root-owned `hook_bin` is the real control.
- **Alternate Claude launchers** — A separate settings tree may keep its own memory notebook. Mitigation: Not merged by this crate. Point a later import at it, or keep using that launcher's store.
